# Experimento Gemini — fonte recebida para consulta

`experimento-anonimizado.html.txt` preserva o HTML grande, incluindo o mapa, a arte e os módulos experimentais, para leitura pelo GitHub. **É fonte de referência, não versão pronta para jogar.** A extensão `.txt` é intencional.

A cópia foi derivada do anexo do usuário. Retirados o ponto da residência, a cena particular da calçada e as posições associadas àquela casa. Família, amigos, cão e nome pessoal do bar foram ficcionalizados; o atalho residencial aponta para o início genérico. Não foram copiados links de e-mail, álbuns pessoais ou rotas que partem de residência. O original particular não foi enviado ao GitHub.

Os novos marcadores não são promovidos a coordenadas OSM verificadas. As posições de parque e Pedra continuam hipóteses incorretas no experimento, preservadas para auditoria; não usar essas posições no jogo. O catálogo em `drafts/` não as habilita.

O código recebido conserva os problemas já descritos na análise, inclusive o acesso a `kawaiiState` antes da inicialização. Não o substituir por `dist/`, não trocar saves e não renomear o arquivo para executar como versão aprovada.

Para evoluir, consultar primeiro `docs/GUIA-REFERENCIAS-LOCAIS.md`, depois o módulo ou trecho necessário desta fonte. A cópia não é byte a byte idêntica ao anexo, pois inclui remoções de dados pessoais. As linhas da análise referem-se ao anexo original.
